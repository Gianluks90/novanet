Buttons

app-ui-button — text buttons (uppercase, accent border, fills on hover).

app-ui-icon-button — icon-only actions. Always pass a label (accessible name + tooltip); link renders an anchor.

Choices

app-ui-segmented — one option out of a few (keyboard: arrows, Home, End).

app-ui-segmented with color options and fill — swatches that share the full width (the accent picker in settings).

app-ui-stepper — quantity − / + (the parent owns the value and the limits; here 0–3).

app-ui-toggle — on/off setting.

Guidelines

  • Use tokens (var(--space-3), var(--radius-sm), var(--duration-base)) instead of literal values.
  • Clickable things are real button/a elements: use app-ui-icon-button / app-ui-button, not a clickable span.
  • Every UI string goes through the t pipe and exists in both en.ts and it.ts.
  • Keep keyboard focus visible (do not remove outlines); motion must respect prefers-reduced-motion (handled globally).
  • Check both themes: light uses a black accent, dark uses the yellow one (customizable per user).
