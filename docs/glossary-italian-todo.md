# Glossario italiano: termini da verificare

Generato il 2026-11-24 dai testi inglesi (NetrunnerDB v3) dei set **System Gateway (SG)**, **Midnight Sun (MS)**, **Magnum Opus (MO**: include "Magnum Opus" e "Magnum Opus Reprint"; non esiste un set chiamato "remastered") e **Parhelion (PH)**.

**Situazione:** in questi set i file ufficiali italiani hanno solo i **titoli** (SG 77, MS 65, PH 63; MO nessuno), non il testo: il testo italiano si trova solo nei PDF di Nisei. Per ogni termine trovi le carte di quei set dove compare: apri il PDF, cerca la carta per titolo italiano e annota come è reso il termine.

**Come compilare:** scrivi la resa italiana nell'ultima colonna. Dove la colonna "Già attestato" dice sì, la radice italiana compare già nei testi ufficiali dell'app e basta confermarla.

**Già nei file ufficiali (per capire lo stile):** ICE = ghiaccio, rez = materializzare, trash = eliminare, purge = epurare, run = incursione, counter = segnalino, host = ospitare, install = installare, access = accedere, HQ/R&D/Archives = QG/R&S/Archivi, subroutine, trace = tracciamento, breaker = rompighiaccio (nel regolamento base: Breaker).

## Suggerimento

Bastano poche carte per coprire quasi tutto: per ogni riga apri la prima della colonna "Carte da controllare" (le più corte, quindi le più facili da leggere).
