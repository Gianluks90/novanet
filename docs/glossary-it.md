# Glossario italiano per le traduzioni automatiche

Guida, non regola assoluta: serve a tradurre in modo coerente i testi delle carte che nei file ufficiali hanno solo il titolo (System Gateway, Midnight Sun, Parhelion, Magnum Opus). Fonte: i testi delle carte Nisei in italiano riportati da te in [glossary-italian-todo.md](glossary-italian-todo.md) + i file ufficiali già presenti nell'app. Quando una carta ha una traduzione ufficiale completa, questa vince sempre.

## Restano in inglese
ICE (anche "pezzo di ghiaccio" → ICE), Icebreaker, Fracter, Decoder, Killer, Code Gate, Sentry, Barrier, AI, AP, Gray Ops, Black Ops, Console, grip, stack, heap, asset, upgrade, tag, subroutine, link, Runner e Corp (nomi propri, senza articolo: "Runner incontra").

## Formato
- Come nei file ufficiali: icone `[credit]`, `[click]`, `[subroutine]`, `[trash]`; i sottotipi richiamati nel testo restano in grassetto e in minuscolo (`<strong>sentry</strong>`, `<strong>virus</strong>`); il testo di promemoria è in `<em>(…)</em>`.
- Forma verbale: seconda persona ("installa", "ottieni", "pesca").
- I nomi delle carte nei testi sono quelli italiani del file ufficiale (es. "Matrioska").
- Il titolo italiano viene dal file ufficiale. Il flavor si traduce (libero, tono letterario); le attribuzioni ("—Nome") e i nomi propri restano.
